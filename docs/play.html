Practise Git without the fear.

A real Git engine, running in this page. Type actual commands and watch the commit graph answer. Merge makes a second parent, rebase abandons the originals, reset leaves them recoverable. Break whatever you like.

Challenge

$

What it understands

add, commit (with --amend), branch, switch, checkout, merge, rebase, reset, revert, cherry-pick, tag, stash, log, reflog, status. References work as they really do: main, HEAD, HEAD~2, HEAD^, a tag, or a short hash.

What the faded circles mean

A commit nothing points at any more. Reset and rebase both leave them behind. They are not gone, and that is the single most reassuring fact in Git: git reflog still lists them, and a reset back to that hash brings the work home.

Where it stops

There is no conflict resolution, no remote, and no file contents; this models the graph, which is the part people find hard. For conflicts see the conflict errors, and for remotes see the diagrams.
