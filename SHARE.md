# Share this with someone stuck

If this saved you once, the most useful thing you can do is put it in front of the next person staring at an error they did not expect. Everything below is ready to use.

## The one that works best

Every answer and every decoded error has its own link. When somebody asks a Git question in a thread, a chat, or a code review, send them the exact fix rather than the front page:

```text
https://amey-thakur.github.io/GIT-GUIDE/#undo-last-commit
https://amey-thakur.github.io/GIT-GUIDE/errors.html#publickey-denied
```

To find the link for any answer, click the `#` beside its heading. One precise link at the moment someone is stuck is worth more than any post.

**One line, for a message or a comment.**

```text
Every Git command with a danger level and its undo. Type what you want to do in plain language,
or paste the exact error Git printed. Free, no ads, works offline.
https://amey-thakur.github.io/GIT-GUIDE/
```

**A short post.**

```text
Four of the ten highest-voted questions in Stack Overflow's history are Git questions.

The gap was never "what is the command". It is "will this destroy my work, and can I get it back".

Git Guide answers both. Type what you want to do, or paste the error Git just printed, and every
command comes with a danger level (safe, rewrites history, destructive) and its own undo. Where no
undo exists, it says so before the command rather than after.

There is also a real Git engine in the page: branch, merge, rebase, and recover work you deliberately
destroyed, with nothing installed and nothing to break.

Free, open source, MIT.
https://amey-thakur.github.io/GIT-GUIDE/
```

## Other ways to help

- **Star the repository.** It is the signal that decides whether the next person finds it.
- **Ask what is missing.** A question the guide cannot answer is a defect report, and it decides what gets added next. [Discussions](https://github.com/Amey-Thakur/GIT-GUIDE/discussions).
- **Print the cards** for your team, lab, or classroom. MIT licensed, no attribution required.
